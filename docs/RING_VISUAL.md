# 星环机图像版 R1

## 基线与范围

承接原版 `69eca71` 路线已合并的深空循环 `37687b6b3ee96392d267612e6f6753665bd46484`，不是后来弃用的指挥界面路线。本次是星环机的视觉与信息交互增量，游戏规则版本仍为 `0.6.0-alpha.1`，存档仍为 `v9 / r3`；release.json 独立标记 `ringVisualVersion: ring-v1` 和 `ringIconCount: 15`。

## 已实现

24格方形跑灯盘保留原位置与动画逻辑，替换为15类独立图标。押注区、历史记录与最近结果使用同一套图像。主界面显示剩余次数、信标等奖励/充能回放数量、出航预留、来源与短结果；全部奖励明细、押注/风险解释和统计仍能展开。

点击图块查看事件说明；信标、充能1段、2段和3段的基础概率直接读取当前规则表。标注的是同类事件总概率，不是单格概率。保底、黑洞保护会改变实际落点，累计历史混合来源，不能直接与某张基础概率表比较。

历史记录支持点击、Enter/空格、Escape关闭；仅展示已经揭晓的内容，不扣次数、不发奖。r3历史没有完整来源字段，只能从既有显式回放前缀区分充能记录，其余统一标注“信标／加注／奖励”，不伪造精确来源。

最近结果在跑灯时显示“正在揭晓”，不会查看待揭晓结果的outcome。派舰充能快捷入口打开真实舰队表单，深空报告入口打开已有实际战报。全部开奖、跳过动画、自动跑灯和充能回放保持可用。

## 素材来源

15个文件位于 `public/icons/ring-v1`，均为本轮编写的原创静态SVG矢量图标，有透明背景、128×128画布、无文本标签烘焙、无字体或外部图像引用。**不是Google Imagen生成的独立高清原画，也不是15张PNG。**

文件名含SHA-256前缀，`src/data/ring-art.json`登记中文含义、路径和完整哈希。构建通过check-ring-art.mjs检查15项覆盖、哈希、安全静态SVG和目录完整性。原有public文件未改，新增资源通过BASE_URL加载。

## 不改动的部分

`src/ui/view.ts`、`src/style.css`、原图标与游戏规则层保持基线字节不变。新样式只作用于`.ring-visual`；建设、研究、舰队页与全站导航不重做。`deep-panel.ts`仅挂接视觉更新，未改变交易/战斗/回收逻辑。没有新增依赖，没有更改存档格式或跨路线迁移规则。

## 验证

本地原323项单元测试保留，新增19项展示模型测试，共342项通过。46项原UI与素材哈希校验、15项独立图标哈希校验通过。本地browser-ring.py的46项隔离DOM检查和既有browser-deep.py的61项隔离DOM检查通过。隔离模式为内存Storage与受控时钟，**不是HTTP或线上验收**。

GitHub常规CI和Pages发布前后均接入browser-ring.py，默认使用真实HTTP、原生localStorage和实时时钟，包含动画、图像解码、记录检查、概率切换、派舰入口、320/390/768/1440px与刷新。真实结果以对应工作流和ring-browser-report.json为准，不能仅凭脚本存在声称通过。

截图存档由规则引擎生成，预置资源与指定场景种子，不是正常开局、玩家存档或自然收益测量。
