# 指挥界面 v1 · 基于 v0.5.0-alpha.2

## 范围

本次按已讨论方向重新组织工作界面，不使用参考游戏的版权美术，也不以概念海报替代 UI。

- 五组左侧导航组织全部 15 个既有入口，保留原解锁条件。星球选择器移至左侧；资源栏仍显示真实库存、净产率、容量及能源。
- 移除宣传横幅；使用页面标题、说明和当前位置。
- 建筑及研究：可搜索、可分类的列表与单对象详情，保留真实成本、前置、收益、时间和升级动作。技术说明折叠查看。
- 建造、研究、造船队列放入共同运行栏，保留取消、退款与暗物质加速。较窄窗口移到内容下方。
- 银河：固定 15 个可选位置，己方/NPC/空位的图形与文字状态，目标情报与真实任务入口。旧坐标列表仍可展开。三环图明确是非比例示意，不是物理轨道模拟。
- 协议：触发、条件、动作三段参数；真实执行原因、简洁空槽、目录筛选与锁定槽位摘要。原参数与顺序操作保留。
- 曲率重置按钮移至曲率说明旁，不再紧靠日常资源操作；真实殖民任务不受影响。
- 手机导航抽屉支持关闭、Escape、焦点约束与背景 inert。关键库存不截断。

## 架构与存档

原 view.ts 原样移动到 controls-view.ts，保留既有动作委托、绑定和控件更新。新 view.ts 只在挂载时重排这些实际节点，不建立另一套经济状态。command-model.ts 提供独立可测试的展示策略；visual.css 替换旧视觉层。

没有修改 src/game、游戏数据、src/core、src/automation、src/prestige 或 main.ts。游戏版本仍为 alpha.2，存档仍为 v9，v8 迁移保护不变；本次用独立“指挥界面 v1”标记和源码 SHA 识别。UI 偏好仅保存在 infinity.ui.inspect.*。

渲染最低间隔 80ms，玩家动作要求立即绘制；模拟、离线与保存仍由原核心处理。银河只有固定 15 个节点，导航为轻量内联 SVG。本次没有引入新框架、字体包或二进制美术；不把未测量的帧率改善写成结果。

## 验证

```sh
npm ci
npm run build
npm test
npm run sim -- 60
npx tsx scripts/p4-fixture.ts > p4-review-save.json
npm run preview -- --host 127.0.0.1 --port 4173
# 另一个终端，安装 scripts/browser-requirements.txt 并准备 Chrome/Chromium 后：
python scripts/browser-smoke.py --verify-dist
```

227 项本地单元测试通过，其中新增 18 项展示策略测试。生产包隔离 DOM 检查覆盖 320/390/768/1280/1600px 的全部页面、股票存量显示、真实升级/取消、协议和抽屉焦点；该检查使用明确的内存 Storage 与受控时钟，不等同于 HTTP 或线上验收。

原生 browser-smoke.py 保留既有存档迁移、资源哈希、全页布局、舰队抵达等验收，并增加搜索、单对象详情、实际队列取消、控件稳定、协议参数及手机导航检查。通过真实界面导航，不强行点击隐藏按钮。远端结果以对应工作流及 browser-report.json 为准。

## 仍未包含

这不是终版玩法交付；没有新增战斗、更高重置、贸易或跨星球自动化。现有图像仍是此前 ChatGPT 生成总览图的切片，不是 Google Imagen 独立原画。功能测试不代替玩家对视觉与交互的评审。
