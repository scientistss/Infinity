## 阶段与验收门槛

1. **存档安全**：备份、写入、读回均成功后才替换内存；失败不谎报成功；不支持的旧档保留原件；已支持的同源 r2 升级可继续；跨标签发现改动立即停止覆盖；异步导入不会覆盖更新后的操作。
2. **星环有限自动执行**：保留手动入口，自动执行默认关闭；真实库存票据与有限次数/支出边界；重复调用不重复结算；中断、资源不足、重置与载入均安全。
3. **有限订单与物流**：研究、建筑、造船从现有付费队列扩展；明确出资/执行星球和稳定任务 ID；真实运输，抵达后付款；超预算等待；取消不会错误取消同位置后来的任务或重复退款。
4. **研究意图与舰队计划**：模板表达目标而不是无限循环；补船计划只完成有限差额；多舰种命名编成可编辑，未引用时可删除；有任务引用时保持身份与可追溯性。
5. **可解释操作与性能**：曲率预览复用实际规则；开拓导航只读；调度有界，减少无效重绘，覆盖重复点击、取消、焦点、后台恢复。

每阶段先本地针对性与完整检查，再提交并推送开发分支，然后从 GitHub 读回提交 SHA，并检查该 SHA 的 CI。不得用本地提交或“push 命令已执行”代替远端确认。若推送失败，优先恢复持久化，不继续累积下一大块。所有新增测试使用匿名合成状态，不包含真实玩家存档。
