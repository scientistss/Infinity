# 曲率收益与损失预览

“发射殖民舰”是曲率重置，不是舰队页的殖民船派遣。曲率页的预览与真实发射共用同一转换规则，展示当前进度实际会得到、失去和保留的内容。

查看、展开说明和切换页面不会发射、扣费、结算舰队、推进游戏时间或消费星环票据。预览不使用外部随机数；真实候选中的成就奖励依据保存的种子计算，只有真正采用新世界才生效。

## 如何看清单

- 收益：规则给出的曲率核心收益，以及实际核心余额、未花费核心被动、新母星库存和成就奖励的前后变化。大数名义收益不冒充实际可表示的余额增加。
- 损失：旧星球的现有资源、建筑、驻留单位和真实未完成队列；在途舰队的实际舰船、货物及尚未入港的权益。进行中研究取消，不退款，已经完成的研究等级保留。
- 停止：旧世界未结束计划终止，未付款工作预留解除；单源运输回执按实际阶段封存。预算、已付费用和历史货物不是当前库存，不再次累计成损失或退款。
- 保留：实际研究等级、暗物质、物品、增益到期时间、曲率科技、长期记录，以及研究模板和编成设计。设计保留不会自动应用研究或补船。

已经造出的舰船按实际所在星球或舰队统计，待造只列剩余数量，避免把整批原订购数量重复计算。过去消耗的燃料不退，但不是这次重置又扣一次。

旧编成订单仍保留创建时的版本、数量和单价快照；曲率后历史引用仍阻止删除该编成。只有明确移除最后的引用记录后，才可以删除设计。星环有限批次停止，但不能因此理解为所有协议配置都关闭；面板按真实结果说明保留与停止范围。

## 刷新与确认

完整预览只在曲率页可见时计算，普通显示最多每秒更新一次；隐藏时不计算，也不在后台保留候选状态。大集合的说明可以折叠或限制明细行数，总量仍来自全部实际数据。

点击手动发射会用最新进度重新计算确认清单，不把旧预览当成执行许可。取消不改变进度、编成填入量或已审阅的计划。

## 手动发射的保存边界

确认后先验证候选存档、写入并读回；成功后才采用新世界并退役旧界面授权。失败保持旧世界的可见进度，按照 SaveSession 的具体结果提示保护或冲突；无效候选被拒绝，不谎报已经发射。

读回失败时，存储字节可能已经改变，因此这里不承诺磁盘回滚或跨标签原子锁。保护模式仍提供原始基线导出。手动发射使用普通保存验证，不额外创建导入/重置那样的不可变备份。

这项先写入再采用保证针对手动发射。协议和离线自动曲率继续使用相同转换规则与既有保存时序；不能将手动保证扩大为每次自动发射都单独持久提交。

本阶段不改变存档 v9/r8、发射门槛、收益公式或旧档迁移规则。存档替换和所有实际换世界路径会使旧预览失效，重新进入时计算当前结果。
