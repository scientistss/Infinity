# Infinity · v0.5.0-alpha.2 视觉与安全升级

本次发布基于 P4 可玩核心，整合实际网站素材替换、v8→v9 升级保护、浏览器验收。不表示完整 P4/P5 或终版玩法已完成。

## 素材来源与落地

使用本对话生成的 **1536×1024 素材总览图**，SHA-256：
`bf44dd0310cf63b77945adb5deff733f83dc3972adbf00e28249d17ce16b14be`。
来源是 **ChatGPT 图像生成工具，不是 Google Imagen**。本次精确裁切、去除标签、压缩并接入网页；没有再次调用模型逐项重绘。不能把切片数量理解成独立高清原画数量。

50 个 WebP：7 场景、5 资源、8 建筑、8 舰船、4 徽章、18 导航符号。合计 **132,074 字节**（约 129 KiB）。裁切坐标、原生尺寸、中文 alt 和逐文件 SHA-256 在 `src/data/art-manifest.json`；`scripts/extract-art.py` 使用原图和 Pillow 可复现。图标等比缩放/补边，场景按容器裁切；不伪造高清 srcset。

资源路径为 `public/art/v1/<name>.<hash>.webp`，只通过 `src/ui/art.ts` 的 BASE_URL 引用，无外链、沙箱路径或写死根目录路径。每次 build 检查文件数、路径、SHA-256、WebP 标识及长度，失败不发布。

页面接入包含顶栏资源、15 标签导航及动态主视觉、建筑/研究/单位卡、银河缩略图、成就徽章和部分星环图块。13 个原有协议卡 SVG 徽记保留以区分动作。若干研究、同族舰船、防御共享切片，尚非每项独立原画；旧资源留在仓库作历史兼容。favicon 同步替换。

文字、数字、按钮、表单、协议配置与反馈都是实时 DOM；图片不参与规则计算。`src/visual.css` 调整深蓝/青金配色、卡片和导航，保留可见键盘焦点及减少动画设置。手机库存数值独占整行，不省略关键数量级。

## 存档升级保护

纯美术更新不再增加信封版本：当前仍为 v9。有效 v9 直接读取，有效 v8 单星球状态明确映射到母星及帝国研究，库存、建筑、三队列、舰船、研究、物品、曲率、协议卡及统计保留；不会重发资源或重复扣队列费用。

本地升级必须先备份原字节并读回一致，才迁移与结算离线。备份失败、损坏文件、v1–v7 和未来版本保留原件，暂停自动保存/卸载写入，运行临时新局供导出。不再静默清空旧进度。手动导入先验证、再备份当前内存状态、最后替换；导入失败不改当前局。明确重新开始也先完成备份。

`infinity.save.backup.original` 永久保留第一份原件；`infinity.save.backup.latest` 保留一次后续替换前的最近快照。存档页“导出保留的原存档”优先读取最近备份；保护模式则直接导出未覆盖的主存档。这不是无限历史记录，也不跨浏览器/设备；建议另存导出的离线原件。

## 验证与发布

本地严格构建和 **209 项单元测试 / 13 个文件**通过，包括用原 P3 代码生成的真实 v8 队列/舰船/研究样本、15 项迁移测试及图像注册表测试。构建期额外校验全部 50 个二进制图像。

`browser-dom-smoke.py` 是受限本地环境的隔离 DOM 辅助测试，不是真实网络/持久化验收。
`browser-smoke.py` 使用真实 HTTP、原生 localStorage、隔离浏览器上下文，验证桌面/390px 各标签布局、图像解码、实际 JS/CSS 和全部新素材哈希、存档迁移/下载/刷新、损坏原件保护以及实时殖民抵达。GitHub CI 执行该脚本；Pages 上线前后再次执行。**实际是否通过以对应 CI 的 browser-report.json 为准，不以截图或脚本存在代替通过。**

通过开发分支 → 中文 PR → squash → Pages 发布，不直接推送 main。`dist/release.json` 标记实际游戏版本、存档版本、素材数量、注册表哈希和源码 SHA，用于检查线上构建。

## 玩法边界

经济倍率、价格、概率、舰队规则与阶段开关不因换图改变。P4 核心殖民/运输/部署/基础侦察已可玩；深空充能、回收、NPC 贸易与军官、跨星球协议卡、更高重置层和战斗不在本次发布范围。主视觉不会解锁未实现内容。
