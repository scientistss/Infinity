# 自然资源成长路径验收

## 范围与复现

本验收候选基于已完整通过 CI 的 [`c7b8217`](https://github.com/scientistss/Infinity/commit/c7b8217bfcd63b0fc13264383be93476e5989a78) 引擎，仅新增测试、说明及 CI 接线；没有带入其他候选的文件导入生产改动。游戏仍为 0.6.9-alpha.1，存档 v9/r8。

`scripts/natural-growth-journey.ts` 从 `createInitialState(20261010, 20261010)` 创建的真实新号出发：500 金属、500 晶体、0 重氢。它使用固定策略调用正式玩家 API，每一步只执行 `tick(state, 1, "live")`。没有追加资源、替换建筑／研究／舰船、改倍率、直接写游戏时间、离线跳时或开奖补贴。

```sh
node --import tsx scripts/natural-growth-journey.ts > natural-growth-report.json 2> natural-growth-report.log
```

这是压缩执行时间的领域验收，不是连续约半小时的人类操作或浏览器试玩。经济和科研采用当前游戏原有倍率。保存信封使用固定日期加已模拟秒数，只用于可复现的元数据，不改变引擎进度。原生浏览器导入这些里程碑属于独立接力验收，不能冒称整条路线在浏览器自然实时完成。

## 已实际通过的首轮片段

本地本次执行在 1789 游戏秒（约 29.82 分钟）通过：

1. 自然产出支付母星基建与六项研究目标；模板逐行核对科技、目标、出资星球、预算及原始意图。
2. 真实付费完成命名编成的两艘小型运输船和一艘轻型战斗机；核查实际库存与相应空造船队列，不以“现货加待造覆盖”代替已经交付。
3. 真实支付殖民船、货物和 232 重氢燃料，在实际舰队抵达后建立 `colony-1`。
4. 母星制造、殖民地科研分工；当前选中母星时，殖民地实际承担计算机技术 2 级。该次独立付款窗口核对两星完整钱包的精确 Decimal 变化，殖民地重氢由 2300 降至 1100，母星只获得正常产出。
5. 殖民地研究所 1→3 的有限计划显式授权母星供货，最多两趟。两支真实运输先交付、后当地付款、再返港；两次燃料各 8 重氢。最终供货船全部返回固定来源。

14 个有限任务全部结清。逐任务从实际付费 job 报价与真实运输燃料独立汇总，精确匹配账本 `charged`；各资源不超过预算、退款为零，任务没有残留 `activeJob` 或 `currentWork`。已发行 job 身份必须从 1 到 `nextJobId - 1` 全部被捕获且唯一，未来策略若出现观测不到的短任务将明确失败，不静默忽略。

## 保存与在途续跑

18 个里程碑分别执行两次严格读回，递归比较整个 `serializeState` 输出：字段存在性、类型、原始数值、数组长度和顺序均不可变，只有对象键插入顺序不属于引擎状态。后续实际从读回对象继续运行。

保存点包括已付款建筑、研究、造船队列，殖民舰在途，以及物流 `pending + outbound`、`pending + returning`、`paid + activeJob` 状态。前 17 个点都有随后的真实 live tick 证据；最后一个点只证明终态已读回采用，明确不宣称它之后也执行过 tick。

每个里程碑附带可独立严格导入的匿名存档，报告保留动作、实际钱包、任务与舰队身份、等待原因、报价、付费回执和逐任务核账。任何阻塞会生成失败报告并返回非零退出码；120 游戏分钟为固定策略首轮的硬上限，不为抽取绿色结果而自动追加资源或延长时间。
