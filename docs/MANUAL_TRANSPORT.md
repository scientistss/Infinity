# 普通手动运输：安全装载辅助

0.6.15-alpha.1 候选仅改普通“运输”的草稿辅助，不增加自动运输、消费授权或存档字段。完整验收与发布以精确提交的 CI 和 release.json 为准。

## 玩家操作

1. 选择自己的另一个星球，填写舰船和速度。运输的货物与预留往返燃料共用货舱。
2. 装载区显示货物占用、总舱、预留燃料与余量；超载仍保留原输入及超额提示。
3. 某资源的“装至上限”只改该项草稿，保留另外两项。它使用点击时的当前库存、航线、舰船、速度和其他货物计算；装重氢时先预留燃料。已有小数输入与库存精度规则保留，不静默取整。
4. 填入不派舰、不扣款、不写入游戏存档。仍需另一次点击原有“派遣舰队”；实际派遣重新执行原航班校验并一次性支付货物与往返燃料。

普通重绘、自然增产和导航不会自动重新装满。舰船、资源或条件变化后显示值不是继续有效的承诺；最终以当前实际派遣校验为准。失败保留草稿并显示原因，不代改目的地、任务、其他货物或派遣数量。非普通运输任务不提供这组辅助。

## 边界

无船、无有效航线、无往返燃料、槽位已满、其他货物无效等情况不能生成有效的填入结果。选中资源自身的无效草稿可以由明确填入操作替换，但不会掩盖其他输入的错误。若大数转成输入文字再解析出现表示尾差，只对选中资源做最多三次、永不向上的规范化；每步不得超过当时库存或剩余货舱，最终文字必须稳定并再次通过真实派遣校验。三次内仍不能稳定、会吞掉其他货物或不能安全表示时，拒绝并保留全部原输入，不自动派遣。其他资源原文和既有经济规则不变。

存档保护时立即禁用辅助。世界替换、恢复或旧节点失效不会复用旧世界的填入能力；按当前提示重新调整草稿。原件恢复仍走既有安全存档会话，不因辅助按钮绕过保护。

## 验收来源

主要路线沿用真实新号成长报告的 `08-colony-established-by-fleet-arrival` 保存点，游戏时刻 1682 秒：母星 `[1:56:11]` 到真实殖民地 `[1:56:10]`，两艘小型运输舰、100% 速度。独立固定边界为总货舱 10000、往返燃料 8、金属上限 9992；保留 500 晶体时金属上限为 9492。自然生产保持，运输后交货、返航与中途保存重载必须核对完整状态和真实舰队身份。

不足燃料等故障场景若使用明确标记的派生测试档，只能证明该故障边界，不算自然取得的状态。受控模拟时间、桌面浏览器响应式视口与独立领域对照，也不能替代真人长时间游玩、实体手机或所有浏览器测试。本候选的实际原生结果尚待精确 CI，脚本存在不代表已通过。
