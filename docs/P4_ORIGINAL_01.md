# 原版续作 P4-1：多星球状态基础

基线：PR #17 / `69eca7107980cce3c4c24ce4736a91993c051fbd`。对应用户指定的原始架构交接文档第 9 节 P4-1；不是从之后的指挥界面分支继续。交接文档本身不提交，也不带入工作环境路径或凭据。

## 本次范围

`GameState.planets[]` 是唯一星球状态，`activePlanetId` 只选择操作对象；每颗星球有 ID、资源、建筑、仓库、产量设置、建造队列、单位和造船队列。研究、曲率、星环机、成就、总时间仍为帝国级。

`activePlanet` / `withPlanet` / `onPlanet` 统一操作边界。建造、取消、造船、生产调节、资源包和星环机奖励只操作选中星球。研究订单记录 `planetId`：付款、排队后开工的实验室和取消/重新定价退款都绑定原出资星球，切换界面不能改变归属。研究期间仍保守地禁止所有实验室升级；任一实验室排队升级时也不接受新研究。研究所网络聚合留给后续增量。

所有星球在同一事件边界冻结速率、推进生产和本地队列；总时间、共享研究、资源加成、信标与协议机每段只推进一次。累计真实产出进入帝国 `lifetime`。离线遵守原有 2–8 小时上限，超出部分不推进任何星球。建造/单位离线日志保留来源星球，避免不同星球的同名完成项混淆。

协议卡解锁可由任一星球满足，但只有一个协议机，动作仍只作用于选中星球；没有默认复制免费自动化。发射殖民舰仍是第一层重置，清空所有星球的本地进度、仅保留新母星；原有共享保留项目不变。

## 原版界面

`src/ui/view.ts`、`src/style.css` 和 `public/` 均与基线逐字节相同。只新增 `ui/planet-selector.ts` 小型适配层：在原顶栏加入原生选择框，单星球时完全隐藏；添加研究付款星球文案，以及必要的存档隔离说明。既有数据表在窄屏使用局部横向滚动容器，避免长数值挤出整页；没有隐藏数值或重做卡片布局。没有改字体、配色、原画或图标，没有引入框架。

## 存档与发布隔离

新结构版本为 v9，额外要求 `schema: "infinity-original-p4"`。当前试验分支的 localStorage 键为 `infinity.original-p4.save.v1`，**不读取或覆盖已上线版本的 `infinity.save.v1`**。同为 v9 的另一分支不代表格式兼容。

本步遵循原交接文档“不迁移 v8”的阶段政策：手动导入旧版拒绝。如果独立开发键中出现较早版本，先备份原字节并读回核对，再返回新局及提示。备份失败、损坏或不支持格式会暂停自动保存，原件保留；“导出”可取回受保护的原始字节。导入有效文件或明确重新开始前也必须备份；不在本步回滚当前网站。

验证要求唯一星球 ID、恰有一个固定 ID 的母星、有效选中 ID、研究付款星球存在、非负有限资源字符串及队列字段。100 颗是文件输入安全限制，不是已设计好的殖民玩法上限。
