# 单源真实运输计划

运输是新建计划时显式开启的有限授权，默认关闭。执行/付款星球、唯一供货星球、单一舰种和数量、速度、最多航次数、累计货物上限、净支出预算在创建后固定。创建本身不付款、不造船、不建前置。旧本地计划继续使用原有调度逻辑。

## 真实经济流程

每十个模拟秒按计划编号检查。先用真实队列检查固定一个下一等级或有限造船批次，生成独立全局 workId 并预留完整价格。预留不扣库存、不占队列。建筑和科研必须先等同目标已有队列真正完成；不会给尚未完成的前置等级之后提前运货。

本地资源够时调用真实入队付款；不够时货单逐资源等于完整缺口，真实 `quoteFlight` 检查固定船只、引擎、槽位、船舱和供货星球库存。所有缺口必须一次装齐，船舱包含往返燃料。造船批量通过有界二分寻找真实合法、预算内、可一次补齐的最大批次；不合并本地和远端钱包。

成功发船在一次不可变事务中扣船、扣货、扣燃料、建立真实舰队、写回执并绑定 workId。燃料计入净支出且永不退款。货物转移不重复算支出。净支出加当前未付工作预留不得超过预算；累计发出货物和航次数不因返货、暂停、取消或刷新而重置。全部保留记录合计最多 256 个航次回执，单计划最多 100 次。

运抵前不能付费，即使本地产出后来已够。真实卸货成功后可在船返航期间付款。同一工作一生最多一船；到货资源被其他行为花掉时，保留工作和运输身份，等待本地产出或玩家手动补货，不再挖取供货星球。旧船未真正返港前，不创建下一工作。

## 取消与生命周期

手动取消付费队列实际退款，并将相同工作恢复为暂停的待付款状态。已完成造船进度保留，只预留未完成数量的原价。同 workId、原目标和 shipmentFleetId 不变。手动召回后暂停，未交付货物要真正返港后才允许恢复该工作的本地付款。

取消整个计划使用一个候选事务组合真实退款和真实召回；任一步身份或精度失败都不提交经济改动。已经卸货的钱留在执行星球，返航燃料不退。外部行为实际完成当前目标时会先真实召回尚未交付的船，再释放工作；日志不作为交付依据。

目标身份按星球 ID 和出发坐标双重锁定，不能卸货给同坐标替代星球。卸货和返港对全部货物与落地船只原子预检。精度失败不部分入库：目的地失败原货返航；母港失败保留原舰队和货物，标记返港入库受阻，暂停自动事件，玩家需明确重试入港。受阻时不能直接恢复计划。

结束的计划如仍有真实返航舰队不可移除记录。殖民发射清除旧世界时，活跃航次标记 prestige-retired，绝不伪称返港或交付，也不额外退款；历史额度与单调 ID 保留。

## 验证边界

保存修订 r6 明确保存 transport/currentWork、nextWorkId 和每舰队的 owner tag。旧 r5 及更早迁移只添加空授权，不认领历史运输。交叉校验验证真实队列、不可变工作、历史回执和舰队的一对一关系、所有预算与不可退燃料下界。运行期的直接发船入口与付款账本也重查真实前置和身份，不能仅凭外层界面或调度器允许。
