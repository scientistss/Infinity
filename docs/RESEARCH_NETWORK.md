# 星际研究网络

本地开发候选 `0.6.17-alpha.1`，格式仍为 `v9/r10`；完整CI与原生验收尚未完成。参与资格、选取次序和支援星移除后的冻结时长是本增量明确补充的规则；不把历史候选实现当成当前已经发布的合同。

本增量把星际研究网络（IRN）的多星球协作接入研究时长。原科技表和实验室门槛以 [DESIGN.md 的研究表](DESIGN.md#研究ogame-移植-p2) 为准；不会降低任何科技的原前置。

## 协作规则

- 付款星球是主实验室所在星球，必须独立满足本项科技的实验室门槛和其他原前置；切换当前浏览星球不会改变已付款研究的归属。
- 已完成的 IRN 等级为 L，最多接入 L 个其他星球的实验室。每个协作实验室都必须已完成至本项科技所需等级，且自己的建造队列里没有实验室升级。
- 合格实验室按已完成等级从高到低选择，同级按稳定星球 ID 排序；主实验室不会重复计入。
- 有效等级等于主实验室等级与所选协作实验室等级之和。IRN 0、单星球或没有合格协作实验室时，仍使用主实验室等级。
- 原有全局互锁不变：任意星球的建造队列含研究实验室时，不能新增研究；研究队列未清空时不能升级实验室。

## 付款、等待和存档

时长仍为 `(已付款金属 + 已付款晶体) / (1000 × (1 + 有效实验室等级)) × 3600 / 600` 秒，最短 1 秒，只在真正开工时确定。研究中的总时长和剩余时长沿用已保存值，之后协作条件变化或协作星球移除都不会重算；旧版已付款但未开工的研究在实际启动时按当时条件计算。

扣费、退款、计划预算、研究队列和付款星球绑定保持原规则。不新增存档版本或实验室参与名单，不把实时推导的协作条件当作历史参与记录。

研究模板与有限计划仍只核对资源预算，并固定付款星球；实验室协作和时长以实际开工条件为准，模板报价不承诺完成时间。

## 界面约定

- 每项科技的“研究时间”使用相同的领域报价模型；有实际合格协作时，在原卡片说明段显示如“当前实验室：主 10 + 协作 13 = 23 级”。不同科技可能得到不同总等级。
- 研究队列标题中的“研究实验室 X 级”仍只指队首付款星球的主实验室，没有队列时指当前星球；不显示一个通用的全帝国有效等级。
- 已付款等待项显示“按当前条件预计 …（开工时确定）”；运行项仅显示已保存的剩余／总时长，不展示推测的历史协作星球。
- IRN 卡片不再显示“多星球后生效”的过时提示。IRN 0 或无协作的其他科技卡片保留原时间和说明文字。

原界面差异仅限以上研究文案、协作时的报价数值及既有全宽说明段；不更换图标、美术或布局。协作等级用短句放在可换行的说明段，不挤占耗时列，320px 下仍须通过后续浏览器检查；单元测试不是布局或截图验证。
