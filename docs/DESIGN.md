# Infinity 设计摘要

**English.** Infinity is an OGame-flavored idle game. The player starts on a planet surface and later pushes through star system, galaxy, universe, and multiverse layers. Each layer should change the verb, not restack the same dimension. Automation is unlockable rule cards and flow blocks (auto-buy, auto-build, auto-explore), never a handwritten script. The single sqrt prestige in v0.1 is a placeholder for leaving the surface, not an Antimatter Dimensions infinity layer.

## 愿景

玩家经营一座不断向外扩张的文明前哨。前期是行星地表上的采矿与冷凝，后期把同一套「看得见的自动化」带到更大的地图上：殖民、航线、宇宙法则、平行世界。数值会变得很大，但决策始终是摆卡片、连流程，而不是写代码。

名字叫 Infinity，指扩张没有预设终点。它不借用 Antimatter Dimensions 的层级结构。

## 和 Antimatter Dimensions 的差别

不做这些：

- 维度链条（上一维生产下一维）
- Infinity Points、Eternity、Reality 以及同构的多层重置货币
- 把「无限」做成重复的指数维度

Infinity 的层级是空间尺度。每一层换一个动词：

| 层 | 玩家在做什么 |
| --- | --- |
| 行星地表 | 开采、建造、摆自动购买卡 |
| 恒星系 | 殖民其他行星，把地表规则复制过去 |
| 星系 | 开辟航线，调度资源与前哨 |
| 宇宙 | 用法则卡改写局部常数，而不是再叠一层维度 |
| 多元宇宙 | 保留平行开局，比较并合并分支 |

v0.1 的「轨道上行」只是离开地表前的占位重置，用来把存档、倍率和重置流程跑通。它以后应被轨道物流取代，而不是长成 AD 的 Infinity。

## 扩张层级

1. **行星地表（v0.1）**  
   金属、晶体、重氢和少量设施。规则卡尚未实装，购买仍是手动的。
2. **恒星系**  
   多颗行星。殖民船是流程块：抵达后自动铺设已解锁的地表规则。
3. **星系**  
   恒星系之间的航线。自动化从「买建筑」变成「派船、均衡库存」。
4. **宇宙**  
   法则卡改变某一片区域的产量曲线或成本曲线。卡片有明确的输入和输出，不能写成脚本。
5. **多元宇宙**  
   平行地表/星系的快照。合并时挑选分支，而不是把层数再乘一层。

## 自动化路线

目标是低门槛的可视化自动化，接近可解锁的规则卡 / 流程块，不是 Bitburner 那种手写脚本。

玩家不写代码。一张卡只有触发器和动作，例如：

- 当金属 ≥ 100，且地表采矿机少于 20 台时，购买 1 台
- 当晶体足够支付下一台晶壳钻探机，并保留 50 金属时，购买最大数量
- 每隔一段时间，对已解锁设施执行一次「买得起就买」

后期的流程块把多张卡串起来，但每一步仍是选好的积木：条件、目标设施、购买数量或「最大」、保留多少资源、开关。没有自由文本、没有循环语法、没有玩家可编程的 API。

计划中的解锁顺序：

1. 单条件自动购买（v0.2 候选）
2. 保留库存后再买
3. 卡片排序与总开关
4. 跨行星复制同一组卡片（恒星系）
5. 自动探索 / 自动殖民（流程块，仍然不是脚本）

## v0.1 行星地表

### 资源

| id | 名称 | 角色 |
| --- | --- | --- |
| `metal` | 金属 Metal | 基础结构材料，类似金属矿 |
| `crystal` | 晶体 Crystal | 中期材料，类似晶体 |
| `deuterium` | 重氢 Deuterium | 稀缺推进剂，类似氘 |

地表始终有风化拾取：每秒 1 金属，再乘上遥测倍率。这样游戏循环在购买之前就看得见。徒手刮取每次 +1 金属，计入本轮累计。

### 设施

价格是几何级数：第 `owned` 台之后的下一台花费 `base * ratio^owned`。一次买 `k` 台的总价是等比数列求和。最大购买对每种资源分别计算买得起的数量，取最小值，并修正浮点误差，保证不会买成负数。

| 设施 | 每台基础产量 | 首价 | 倍率 |
| --- | --- | --- | --- |
| 地表采矿机 Surface Miner | 金属 +1/s | 金属 10 | 1.15 |
| 晶壳钻探机 Crust Drill | 晶体 +0.2/s | 金属 80 | 1.16 |
| 重氢冷凝井 Deuterium Well | 重氢 +0.1/s | 金属 150，晶体 30 | 1.17 |
| 磁选熔炉 Magnetic Smelter | 金属 +8/s | 金属 250，晶体 60 | 1.18 |
| 前哨勘测塔 Survey Outpost | 晶体 +1.2/s，重氢 +0.35/s | 金属 600，晶体 180，重氢 30 | 1.20 |

产量（含风化）再乘 `1 + √遥测`。界面上的每秒产量和每台产量都含这个倍率。

### 循环

`tick(state, dt)` 是纯函数，不修改入参。`dt` 以秒计。帧间隔很短时逐帧调用；离线或后台间隔较大时，一次调用补完被上限截断后的时间。产量对时间是线性的，所以不需要在 tick 内部分步。

### 轨道上行（Sqrt 占位）

本轮扩张分：

```text
score = 金属累计 + 5 × 晶体累计 + 20 × 重氢累计
gain  = floor(sqrt(score / 200))
```

`gain < 1` 时不能上行。上行后：

- 清空资源、设施、本轮累计
- 遥测增加 `gain`
- 保留累计游玩时间
- 之后所有产量 × `(1 + √遥测)`

这是唯一的重置层，而且奖励曲线是平方根，用来和「再叠一个指数维度」区分开。

## 存档与离线

本地键名：`infinity.save.v1`。

```json
{
  "version": 1,
  "savedAt": 1710000000000,
  "state": {}
}
```

- `version` 目前只接受 `1`
- `savedAt` 是毫秒时间戳
- `state` 里的大数写成十进制字符串，由 `break_infinity.js` 的薄封装读写

启动时用 `now - savedAt` 结算离线，**上限 8 小时**。超过的部分丢弃，并在界面写明上限。导入 JSON 只恢复快照，不按文件里的 `savedAt` 再发一笔离线收益。购买、上行、隐藏页面和关闭页面前都会写回本地。自动保存间隔 15 秒。

大数全部经过 `src/game/decimal.ts`。规则代码不直接依赖具体的大数库。

## v0.1 范围

做了：

- Vite + TypeScript 壳，无 UI 框架
- 纯 `tick`、三种资源、五座设施、购买 1 / 最大购买
- 一层 Sqrt 声望占位
- localStorage、导出 / 导入 JSON、8 小时离线上限

不做：

- 规则卡和流程块的实际逻辑
- 恒星系及以上的地图
- 战斗、科技树、多存档槽、云存档
- 手写脚本、模组 API
- Phaser 或其他游戏引擎

v0.1 的成功标准是：打开页面能看到资源增长，能买设施，能买最大数量，能保存并在刷新后继续，能导出一份带 `version`、`savedAt`、`state` 的 JSON。
