# 跨星实验室占用定位

已交付版本 **0.6.24-alpha.1 / v9/r14**，精确来源为 [9a27ed8](https://github.com/scientistss/Infinity/commit/9a27ed8c198a19f6bab9578e3d8d26ee22cdfc13)。只读实验室占用定位已通过五个必需 CI 作业、汇总门禁与精确产物发布。玩家入口为研究页的“研究受阻”摘要，展开后查看各星球实际实验室工作。

## 玩家能看到什么

研究页出现简短的“研究受阻：N 处实验室施工”摘要。展开后列出实际占用实验室的星球名称和坐标、升级或拆除、目标等级、已付款工作身份及排队位置。

- N 按有实际实验室工作的星球计数，详情另列实际工作总数，包含已付款排队项。
- 队首已开工与队尾已付款排队分别标明；尚未付款的计划或模板不是施工。
- 不估算整个帝国的解锁时间，也不把队尾单项时长当成总等待时间。
- 保护模式明确标记显示的是冻结的已采用进度；完成、取消、采用新存档或重置后重新推导。
- 展开与收起只改变界面，不改变选中星球、存档、研究、资源、工作或执行权限。

本增量不增加跳星、取消、研究或模板操作。原实验室互锁、研究报价、付款、按钮可用条件与实际执行规则保持原样。

## 推导与展示边界

只读取当前已采用状态中各星球的真实建造队列和拆除工作。研究页需要展示时进行一次全帝国扫描，形成与游戏对象脱离的显示数据；科技卡不重复扫描这一列表。隐藏页不保留旧世界的明细权威。

星球名称及其余动态内容使用文本节点，不解释为 HTML。相同星名以坐标区分，工作以稳定任务身份区分。长名称需在窄屏换行，不扩展原美术范围。

## 验收合同

1. 独立字面期望覆盖异星队首、队尾、多星、多工作、拆除、同名不同坐标与无阻塞；模型调用前后完整状态相同。
2. 从有准确来源和摘要的双星自然研究网络存档接续，真实付款升级研究所、切到另一星球研究页，再完成或取消，逐节点核对完整经济和任务状态。
3. 320、390、768、1440 四宽验证短摘要、明细全文、真实操作命中和截图前后状态。合成的长名称、队尾及故障场景与自然续程分别标明。
4. 保护、跨标签、导入与新世界边界保留原始存档和完整状态证据；查看不得触发任何经济操作。
5. 原四个必需 CI 作业和性能观察窗口保留；新增独立 15 分钟上限的原生作业。最终汇总要求五个作业全成功，并绑定同一源码、构建资源和运行身份。新增作业使用额外独立 runner，不能宣称没有额外验收资源成本。
