## 本轮可玩流程

银河浏览 → 选空位 → 编成殖民船和护航 → 装载资源 → 预览时长/燃料/货舱 → 派遣 → 抵达创建殖民地 → 护航返航 → 星球切换、运输或部署。第二颗星球由舰队抵达创建，不由正常新局或界面按钮直接赠送。

银河为 5×100×15 个行星位置加第 16 位深空；星系和银河距离环形。新局母星由独立宇宙种子落在银河 1、40–60 系、4–12 位，母星仍为 40°C、163 格。NPC 是种子确定的基础邻居，约 25% 占位；不模拟成长、军力、排名、贸易或反击。浏览不改变星环机 RNG。

实际任务为运输、部署、殖民、基础侦察；支持召回与消息。最慢舰种决定速度，完成的引擎研究决定发动机，超空间技术每级货舱 +5%。舰队槽为 1+计算机，殖民地名额为 ceil(天体物理/2)，出发时同时预留名额与目标。成功殖民只消耗一艘殖民船，剩余舰船返回；失败则携原货返航。

生产、队列、舰队在同一事件边界推进，离线也走相同路径且受原上限约束；货物运输不重复计入生产。运输导致超仓时保留货物、暂停自然生产；部署把舰船留下。取消和重复到达不能复制船与资源。研究或在途舰队关联的殖民地不能放弃；放弃需明确确认。第一层重置清空舰队和殖民地，保留同一宇宙种子与递增舰队编号。

## 与原始交接文档的对应与偏差

本轮覆盖 P4-2 的空间浏览、P4-3 的舰队核心，以及 P4-4 的殖民部分。不表示 P4-2 的 NPC 成长曲线、P4-4 的回收/拆除/地形改造器全部完成。

参考交接文档的飞行例子：距离 2795、船速 5000、10% 档，对应约 69.0426 游戏秒。`speedPercent` 用 10–100 表示，公式是 `(10 + 35000/speedPercent * sqrt(10*d/v)) / 120`。

交接摘要未提供完整温度/格子分布和油耗细则，当前明确沿用早先本项目舰队核心的工程取舍，而非声称逐项复刻 OGame：殖民地格子为 120–239，温度为位置线性曲线加确定性扰动；母星不吃位置矿产加成以维持原版节奏。殖民地的 1–3 位晶体和 6–10 位金属倍率按摘要，作用于矿产不作用于基础产出或能源。

燃料按各舰种速度节流计算并预付往返，部署也预付往返，召回不退；燃料与货物共用容量。以后完善部署燃油细节时应独立更新报价、状态及测试。

运行防护上限：100 颗星球、1000 支在途舰队、每舰种单次派遣不超过 1e12、消息保留 150 条。这些是工程边界，不是假装无穷规模。

## 验证
