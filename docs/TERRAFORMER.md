# 地形改造器

当前为0.6.16-alpha.1候选，准确CI和网页发布仍需独立完成。

## 怎么使用

- 本星纳米机器人工厂1、帝国能源技术12完成后，查看建筑页的地形改造器。
- 一级花费晶体50000、重氢100000，需要当前供能1000；二级需供能2000。能源只在付款入队时检查，不消耗，也不要求剩余电力。
- 新付款入队后不立刻增加格子。真实完成一级增加总格5，建筑自身占1格，可用格净增4。
- 已付款队列仍占格子。星球已满时不能利用未来扩格提前入队；总格最多10000，不能先收费再截断奖励。
- 入队后供电下降不会停工或额外收费。取消未完成项目沿用真实付款退款，不获得格子。

有限建筑计划、运输计划和意图模板共享相同付款校验。供能不足时等待，不发运输船补“能源”。模板只保存目标；核对价格和预算后才创建有限计划，真正付款仍在当前条件满足时发生。

## 旧存档

r10先保留旧原件，再验证并采用升级。旧星球上限、已有等级和原付款工作保持历史语义，不按旧地形等级追溯补格。

旧队列明确显示“旧版已付：完成升级，不增加格数”。这是兼容旧存档中合法跳级、重复目标和10000格已付状态的新增规则选择；本版新付款入队才适用扩格。该星旧地形项目完成或由玩家明确取消前，不再接受新地形付款，其他合法进度照常。

两星的付款与格子各归自己的星球，不随页面选择转移。曲率清除本轮建筑和授格账，新母星回到正常163格；保留模板不等于保留旧付款权限。
