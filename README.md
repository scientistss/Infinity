# Infinity · 无限

从荒芜行星开始的单机网页科幻放置游戏：建设矿场与研究、组装可视化协议卡、建立殖民地，派舰深入深空。多人相关内容逐步 NPC 化；当前没有后端或真实付费。

**当前隔离私人试玩交付版本 `0.6.30-alpha.1`，存档 `v9 / r14`，精确游戏来源 [`6f73735`](https://github.com/scientistss/Infinity/commit/6f73735534ffc1b0e47a01935d8c6e3ff786c989)。** 深空操作面板另标 `deep-r2`，星环机图像版为 `ring-v1`；各站实际部署提交仍须核对其 `release.json`。这是可玩的开发版本，不是整套规划或 OGame 全部玩法已经完成。

**r14 历史侦察快照与显式战前演练已完成精确提交验收并发布。** 保留 r13 的真实付费轨道战斗、永久战损、一次返港结算与紧凑战报；新增消息内的精确历史快照、三个固定公开种子示例和空载攻击草稿填入，实际付款仍需独立派遣。详见 [r14 验收、发布与性能边界](docs/NPC_SCOUT_REHEARSAL_ACCEPTANCE.md)及 [r13 历史轨道验收](docs/NPC_ORBITAL_ACCEPTANCE.md)。NPC 自主成长、反击与完整行星战争仍未完成。

本批已交付历史侦察对照、编成数量复制到演练、跨星实验室阻塞定位、手动舰船／防御付款确认、只读回收预估、同次渲染舰队行索引，以及天体物理学解锁说明的小幅显示修正。最后一项仅删除过期后缀，仍由实际完成的天体物理学 1 级解锁星环机，不增加玩法或改变经济／存档。七个大小不同的增量不代表路线图完成比例；精确来源、独立验收、玩家入口与未完成项见 [2026-10-13 交付记录](docs/BATCH_DELIVERY_20261013.md)。

## 当前路线与内容

以原始 `69eca71`（PR #17）代码和交接要求继续，保留原版导航、卡片、资源栏和配色，不使用后来弃用的指挥界面。

经济建设包含三资源、能源约束、等级建筑、仓库、研究及三条队列；协议卡、曲率重置、暗物质道具、14类舰船和10类防御继续可用。多星球拥有独立库存和本地队列，研究共享并记录出资星球。

地形改造器已接入真实付款、供能及完成授格；星际研究网络提供符合前置条件的多星实验室协作。普通拆除 A 已支持本星手动单级付款、取消、完工释放一格及重新建设，尚无批量或自动拆除。

新增本地有限计划：建筑/研究达到指定等级，造船完成指定新增数量；固定执行与付款星球，设置三资源预算，使用真实付费队列和稳定任务身份。本地单计划可先查看按当前规则计算的未付费用，再明确填入草稿预算；查看和填入都不付款，造船数量始终是额外新增。目标、付款星球、价格或付费队列改变后需重新查看，运输模式不提供填预算。暂停不撤销已付工作，取消按真实未完成部分退款。可选单源补给默认关闭，明确限定来源、舰种、趟数与毛货物上限；通过真实运输抵达后才付款，每个子任务最多补给一次，燃料不退。

普通手动运输可查看货物、预留往返燃料与货舱余量，并显式将一种资源装至当前可行上限；填入只改草稿，其他货物保持，仍需另行派遣。库存、舰船、速度和目标变化会重新计算，失败不改原输入。详见 [手动运输装载](docs/MANUAL_TRANSPORT.md)。

银河与舰队已支持运输、部署、殖民、基础侦察、回收和深空充能。第16位驻留1–3段后生成实际事件，奖励随舰队返航入库；星环机回放不重复发奖。天体物理学 1 级解锁星环，手动开奖 10 次后解锁自动跑灯卡，装配默认关闭。有限自动批次需明确授权现有票据、固定出资星球与押注、设置重氢总扣费上限；仅打开卡片开关不会产生授权，新信标和奖励票据不会自动加入，赢回也不恢复额度。商人采用限时固定报价；黑洞有明确保护规则；海盗和异星遭遇采用六回合编队聚合战斗，有实际战损和残骸。**这不是 OGame 逐舰随机战斗模型；NPC 有界轨道战斗另见下文，完整行星战争仍未开放。**

深空操作面板显示在途阶段、倒计时、报告筛选、召回和折叠的回合详情。15类独立静态SVG统一星环机、押注、历史与深空事件图标；它们不是 Google Imagen 独立原画。

NPC 保留固定生产，并已在 r13 接入坐标钱包、永久驻军战损、最多六轮轨道战斗及整数战利品返港。真实侦察抵达才生成当时快照，旧报告不随之后的生产或战损刷新。最多 512 个永久目标、64 个未完攻击和 60 份终端战报，必要活报告另行保留；精度或容量受阻会保留货物与幸存舰船。紧凑摘要展示结果与交付状态，展开保留精确原始数据，查看不领奖。NPC 自主消费、经营成长、排名奖励与全面行星战争仍未完成。详见 [轨道合同](docs/NPC_ORBITAL_ATTACK.md)及 [r12 历史经济验收](docs/NPC_ECONOMY_ACCEPTANCE.md)。

历史侦察演练的玩家路径是：满足间谍卫星的船厂 3、燃烧引擎 3、间谍技术 2 门槛并实际造船 → 付费侦察抵达 NPC → 在消息页打开该份历史侦察演练 → 选择当前星球实际停泊舰船并运行三个公开种子示例 → 明确填入攻击草稿（空载） → 在舰队页单独付费出征。攻击仍要求武器技术 1、所选舰船前置、燃料和航班容量；排队中的科技不算已完成。三个示例不代表统计胜率或损失／战利品保证，真实抵达时敌我状态可能不同。旧文本报告没有精确快照，保留原文并提示重新付费侦察，不从舍入文字伪造情报。详见 [侦察演练合同](docs/NPC_SCOUT_REHEARSAL.md)。

研究模板仅保存命名目标意图。应用时明确选择付款星球、重新报价并分别确认预算，原子创建有限研究计划；编辑或删除模板不会改变已有计划。已有目标覆盖与冲突会在审阅中列明，不复制旧执行授权。

建筑模板同样只保留命名的绝对目标等级；应用时固定一个本地执行／付款星球，列出已付工作与已有目标覆盖，逐项明确有限预算并重新确认。编辑只影响未来，不自动补前置建筑或跨星搬运。

命名多舰种编成只保存数量设计。明确填入才改变派遣数量；一次性补船按固定星球现货和已付队列计算缺额，锁定数量和独立预算，出航或战损不自动续补。编辑只影响未来，有保留计划引用时不可删除。

曲率页显示同一实际重置规则生成的收益、损失和保留项。查看不执行重置；手动确认始终重新计算，并在存档写入及读回成功后才采用新世界。

银河页提供折叠的只读开拓查看：检视当前恒星系的占用、真实名额与有限场景报价；查看不切换实际星球、不填写派遣，也不创建任何工作。空位不等于已经满足出航条件。

## 存档与安全

存档键为 `infinity.original-p4.save.v1`，格式要求 `schema: infinity-original-p4`、version 9、revision 14。受支持的旧格式来自本仓库 Git 源码谱系的 v9/r2–r13，并须通过完整结构与跨引用校验；先备份、写入并读回，再确认升级。不支持或损坏的原件进入保护模式，不静默覆盖。文件先只读校验，显示来源版本和当前进度，经再次确认后才授权替换；取消不写入。导入与重置也只在落盘验证成功后替换当前进度；备份或写入失败会冻结游戏并保留原始导出。观察到其他标签页改动时，本页暂停写入，需刷新读取最新进度；这不是跨进程原子锁。保护期间星环操作同步禁用并显示冻结原因；保留批次记录不等于已执行停止。

r2–r12 先经各自完整验证链，再把实际 NPC 库存迁入 r13 钱包并初始化零权益；r2–r11 的前代经济从年龄 0 开始，不按旧 `totalTime` 补发资源。已有授格、付款与拆除账保留，之后仅按既有规则采用一次受限离线时间。完整 r13 的权益与在途账先按原合同验证；r14 只为旧消息追加显式空快照槽，不重建钱包或补发情报。早期未发布 r13 缺权益字段、当前 r14 缺快照槽或无效快照均进入保护，不静默修补。曲率与弃星会明确提示相应本地权益损失。

原站 `infinity.save.v1` 保留，游戏提供导出旧站原始存档。**保留旧字节不等于可以跨路线导入；schema、版本和修订号相同也不证明兼容。** 已识别的另一条 `0.7.0-alpha.3` 路线同样标记 v9/r6，实际结构却不同，当前会安全拒绝并保护原件，尚未迁移。原版 r1、v8 也不迁移。具体边界见 [安全存档会话](docs/SAVE_SESSION.md)；导入测试存档前先导出自己的进度。

“殖民船”是可派遣舰船；“发射殖民舰”是第一层曲率重置，清空本轮各星球与在途舰队。请阅读游戏中的确认说明。

## 运行

验证环境使用 Node.js 22、npm 10。保留锁文件：

```sh
npm ci
npm run dev
# 按终端地址打开 /Infinity/
npm run build
npm run preview
npm test
npm run sim -- 60
```

仓库 GitHub Pages 入口：https://scientistss.github.io/Infinity/ 。此入口不单独证明本次隔离试玩发布；版本以所访问站点的 `release.json` 为准。

生产包必须通过 HTTP 服务访问，不能直接双击 index.html。素材使用 Vite BASE_URL，不写死根目录。通过主题分支、中文 PR、检查后 squash 合并再发布，不直接推送 main 或强推。

`--inline` 浏览器模式是导航受限环境的辅助检查，使用内存Storage和受控时钟，不能代替原生HTTP或公网验收。演示和验收使用明确预置的合成状态或选定种子；`npm run sim -- 60` 是加速引擎策略模拟，不能当作 60 分钟自然时间浏览器试玩或长期平衡结论。响应式视口检查也不等于用户 Windows 电脑、真实手机或 Safari 验收；极限组合性能限制见 [表现与性能验收](docs/PRESENTATION_PERFORMANCE.md)。

跨星球已支持明确授权的单来源有限订单补给；多来源持续供给、完整 NPC 星区经济／经营成长／排名与另一条路线的任务计划系统尚未恢复或实现。有界轨道战斗、永久战损、返港结算和历史侦察演练已接入实际存档与 UI；这些子能力不等于完整行星战争。军官、月球与战略设施、全面战争外交、扩展拆除、高层重置和独立Imagen原画仍未完成。命名编成的一次补船不持续维持库存，研究模板不自动循环应用。

库存等使用大数，但舰船、事件和空间集合仍有工程上限。当前 6f 相对固定旧 4b 的累计性能检查完成 12 次运行／6 对配对／36 个固定窗口、313 项检查；普通三个页面 Task 中位约 52–67 ms／墙钟秒，样本内无稳态长任务。极端舰队页 Task 中位约 783 ms／墙钟秒，RAF 间隔 p95 为 50 ms，三个固定窗口共 16 次 ≥50 ms 长任务。它混合多个功能阶段，不能归因于本次文案修正；不宣称整体提速、60 fps 或 Save 优化。详见 [当前性能边界](docs/RESEARCH_UNLOCK_COPY.md#性能与覆盖边界)。

历史 e729 / r14 的短时原生样本中，普通负载 Task 约 28–38ms/s，未观察到稳态 ≥50ms 长任务，导航 EventTiming P95 为 40ms；极端舰队页 Task 中位约 623→685ms/s，导航 P95 仍为 160ms，启动约 292→427ms，仍有明显卡顿。对照从固定 `4bceefee` 跨越多个功能阶段到 r14，不能归因为侦察演练的独立效果，也不能宣称整体提速或极限流畅；详见 [本次性能范围](docs/NPC_SCOUT_REHEARSAL_ACCEPTANCE.md#性能与覆盖限制)。
