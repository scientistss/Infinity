# Infinity · 无限

从荒芜行星开始的单机网页科幻放置游戏：建设矿场与研究、组装可视化协议卡、建立殖民地，派舰深入深空。多人相关内容逐步 NPC 化；当前没有后端或真实付费。

**游戏版本 `0.6.1-alpha.1`，存档 `v9 / r4`。** 本次深空操作面板另标 `deep-r2`，星环机图像版为 `ring-v1`；实际部署提交见网站 `release.json`。这是可玩的开发版本，不是整套规划或 OGame 全部玩法已经完成。

## 当前路线与内容

以原始 `69eca71`（PR #17）代码和交接要求继续，保留原版导航、卡片、资源栏和配色，不使用后来弃用的指挥界面。

经济建设包含三资源、能源约束、等级建筑、仓库、研究及三条队列；协议卡、曲率重置、暗物质道具、14类舰船和10类防御继续可用。多星球拥有独立库存和本地队列，研究共享并记录出资星球。

银河与舰队已支持运输、部署、殖民、基础侦察、回收和深空充能。第16位驻留1–3段后生成实际事件，奖励随舰队返航入库；星环机回放不重复发奖。手动开奖 10 次后可解锁有限自动批次：需明确授权现有票据、固定出资星球与押注、设置重氢总扣费上限；新信标和奖励票据不会自动加入，赢回也不恢复额度。商人采用限时固定报价；黑洞有明确保护规则；海盗和异星遭遇采用六回合编队聚合战斗，有实际战损和残骸。**这不是 OGame 逐舰随机战斗模型，也没有开放 NPC 行星战争。**

深空操作面板显示在途阶段、倒计时、报告筛选、召回和折叠的回合详情。15类独立静态SVG统一星环机、押注、历史与深空事件图标；它们不是 Google Imagen 独立原画。

## 存档与安全

存档键为 `infinity.original-p4.save.v1`，格式要求 `schema: infinity-original-p4`、version 9、revision 4。有效同源 r2/r3 先备份、写入并读回校验，再确认升级；不支持或损坏的原件进入保护模式，不静默覆盖。导入与重置也只在落盘验证成功后替换当前进度；备份或写入失败会冻结游戏并保留原始导出。其他标签页改动存档后，本页暂停写入，需刷新读取最新进度。

原站 `infinity.save.v1` 保留，游戏提供导出旧站原始存档。**保留旧字节不等于可以跨路线导入。** 原版r1、v8和另一条路线的v9不迁移。导入测试存档前先导出自己的进度。

“殖民船”是可派遣舰船；“发射殖民舰”是第一层曲率重置，清空本轮各星球与在途舰队。请阅读游戏中的确认说明。

## 运行

验证环境使用 Node.js 22、npm 10。保留锁文件：

```sh
npm ci
npm run dev
# 按终端地址打开 /Infinity/
npm run build
npm run preview
npm test
npm run sim -- 60
```

GitHub Pages：https://scientistss.github.io/Infinity/

生产包必须通过 HTTP 服务访问，不能直接双击 index.html。素材使用 Vite BASE_URL，不写死根目录。通过主题分支、中文 PR、检查后 squash 合并再发布，不直接推送 main 或强推。

## 验证与未完成

构建检查原版UI／素材哈希和15项星环图标；单元测试、原引擎回归、数值模拟、原生HTTP/localStorage浏览器检查由CI执行。Pages发布前后均有实际浏览器验收和全部部署文件哈希验证。失败截图与报告存入Actions产物；脚本存在不代表检查通过。

`--inline` 浏览器模式是导航受限环境的辅助检查，使用内存Storage和受控时钟，不能代替原生HTTP或公网验收。所有演示存档都预置了资源或选定测试种子，不是自然开局进度。

跨星球自动化、NPC完整经济／排名、军官、月球与战略设施、全面战争外交、建筑拆除／地形改造、高层重置和独立Imagen原画尚未全部实现。库存等使用大数，但舰船、事件和空间集合仍有工程上限，不宣称无限数值已完成。
